About This Lab

This laboratory activity focuses on understanding the CSS Box Model and basic webpage layouts. It demonstrates how content, padding, borders, and margins work together to organize and structure webpage elements.

Through this activity, we explore CSS properties and Flexbox to create an organized layout, improve spacing, and position elements properly. We also learn how responsive design helps a webpage adjust to different screen sizes.

The goal of this exercise is to develop a better understanding of CSS styling and layout techniques while building a simple and functional IT portfolio.
